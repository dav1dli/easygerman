# Glossar: O. Henry

Most stories are independent. Keep English personal and place names in their original form (Della, Jim, Soapy, Broadway, New York). Recurring names:

| English | Deutsch |
|---|---|
| Jeff Peters, Andy Tucker | Jeff Peters, Andy Tucker (con men; Jeff narrates) |
| Bagdad on the Subway (New York) | Bagdad an der U-Bahn |
| The Four Million | die vier Millionen |
| the Cisco Kid | der Cisco Kid |
| ranger, ranch, ranchero | der Ranger, die Ranch, der Rancher |
| dollars and cents | Dollar und Cent |
| scene break "/" in source | `* * *` |
| "—from <collection> (year)" lines at story ends | omit (editorial) |
| the Cisco Kid / El Chivato | der Cisco Kid, «Herr Kid» / El Chivato («das Zicklein») |
| croaker (doctor, slang) | der Knochenflicker |
| jacal | der Jacal (Hütte) |
| Herkimer's Handbook of Indispensable Information | Herkimers Handbuch des unentbehrlichen Wissens |
| Jeff Peters / Andy Tucker narration | casual, Perfekt allowed |
| stir (prison), crack a safe | der Knast, einen Geldschrank knacken |
