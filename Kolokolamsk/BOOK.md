# Ungewöhnliche Geschichten aus der Stadt Kolokolamsk
Ilja Ilf, Jewgeni Petrow.

Source: `Sources/Ilf, Petrov, 12 Stuliev.pdf`, PDF pages 642–679: «Необыкновенные истории из жизни города Колоколамска» (Russian, 1928–1929, public domain). There are 11 short satirical stories set in the same fictional small town, with recurring townspeople.
Extraction: `.venv/bin/python scripts/extract_images.py kolokolamsk` and `python3 scripts/ilf_petrov_pdf.py kolokolamsk` → `source/chNN.txt`.
